The python environment for this project is managed by `uv`. Use `uv run` for python commands.

LaTeX is installed at `/usr/local/texlive/2026/bin/x86_64-linux`. Non-interactive shells may not include this directory on `PATH`; use the absolute path, e.g. `/usr/local/texlive/2026/bin/x86_64-linux/pdflatex`, when `pdflatex` is not found.
